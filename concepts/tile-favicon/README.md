# Mahjoffg · 一筒 favicon

一块 3:4 的麻将牌：白牌面压在天蓝底座上，牌面中央是一筒的圆环加圆心。只用页面自己的两个颜色
`#49A5E8` 和 `#FFFFFF`，外加两者的混色。

```sh
node make-favicon.mjs
```

零依赖（自带光栅器和 PNG 编码器）。写出 `out/`，再把写出的文件读回来逐像素检查；任何一项不过就以非零退出。

| 产物 | 用途 |
| --- | --- |
| `out/mahjoffg-tile-<tag>-16.png` | 标签栏，1x 屏 |
| `out/mahjoffg-tile-<tag>-32.png` | 标签栏，Retina |
| `out/mahjoffg-tile-<tag>-180.png` | `apple-touch-icon`，不透明 |
| `out/mahjoffg-tile-<tag>.svg` | 母版，不挂到页面上（见下） |
| `out/src/*.svg` | 16 和 180 两个 PNG 各自对应的矢量，用来让浏览器重画一遍做对照 |

项目根目录的三个 `mahjoffg-tile-*.png` 是 `out/` 里同名文件的逐字节副本，`build/dist.mjs` 发布的是根目录那份。
换图标时改 `make-favicon.mjs` 里的 `TAG`（沿用「日期 + 字母」的防缓存命名），重新生成后复制到根目录，
再改 `index.html` 的四条 `<link>` 和 `build/dist.mjs` 的 `SHIP`。

## 几何

全部画在 32 格空间里，**每条直边都是偶数**，所以同一张图在 32px 和 16px 下都落在整像素上。

| 部件 | 32 格坐标 | 说明 |
| --- | --- | --- |
| 底座 | 圆角矩形 (4,4)–(28,32)，r 4，`#49A5E8` | 牌面那块板下移 4 格，只露出最底下 4 格 ＝ 牌的厚度 |
| 牌边 | 圆角矩形 (4,0)–(28,28)，r 4，`#89C5F0` | 65% 天蓝；白牌面在白色标签上靠它不消失 |
| 牌面 | 圆角矩形 (6,2)–(26,26)，r 2，白 | |
| 圆环 | 圆心 (16,14)，外半径 8 | 外径 16 ＝ 牌面宽度的 80% |
| 环芯 | 32px 起：点 3 · 留白 2 · 环 3；16px：点 2 · 留白 2 · 环 4 | 16px 下只有后者能让每个半径都是整像素 |

牌边用浅色、底座用实色，是为了让它读成「一块有厚度的牌」。整圈同色描边的版本轮廓更强，但竖长圆角框加一个圆，
看上去像洗衣机或音箱。

180px 是满铺的不透明天蓝方块（iOS 会把透明像素填黑，圆角也由它自己裁）。天蓝底上白牌不需要牌边，
实蓝底座又会融进背景，所以牌边去掉、侧面换成 45% 天蓝 `#ADD7F5`。牌放大 4 倍 ＝ 96×128，仍然像素对齐。

## 为什么不把 SVG 挂成 favicon

母版带的是 32px 那套环芯（3·2·3）。Chrome 在 1x 屏上会按 16px 渲染它，圆心落不到整像素上，中心会发软。
图标是纯两色、不需要随深色模式切换，PNG 已经够用。

## 与浏览器的对照

把 `out/` 里的 SVG 交给 Chrome 152 光栅化后和 PNG 逐像素比较：平涂像素全部一致（16px 190/190；
32px 862 个里 2 个差 ≤3/255），差异只出现在曲线的抗锯齿像素上（平均约 11/255）——Skia 的曲线抗锯齿比精确面积覆盖略重，
不是几何不一致。
